# Upstream WeRead V2 architecture and Python port guidance

Scope: primary sources on `zhaohongxuan/obsidian-weread-plugin` `main`, pinned at commit [`5d3b421`](https://github.com/zhaohongxuan/obsidian-weread-plugin/tree/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b). The upstream guide is useful intent documentation, but the source code below is authoritative where they differ.

## Architecture

- **API-key authentication.** `settings.ts` persists `wereadApiKey` and its validation state with the rest of the plugin settings. `settingTab.ts` masks the input, validates it on opening settings, clears it on logout, and can bootstrap it from a Cookie-authenticated session. `ApiManager.fetchAndSaveApiKey()` calls `GET /api/skills/apikeyGet`; `ApiV2Manager.callAgent()` sends it as `Authorization: Bearer …`. The value is UI-masked but stored in plugin data, not an OS credential store. Sources: [`src/settings.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/settings.ts), [`src/settingTab.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/settingTab.ts), [`src/api.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api.ts), [`src/api-v2.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api-v2.ts).

- **Gateway request contract.** `ApiV2Manager.callAgent()` posts to `https://i.weread.qq.com/api/agent/gateway` with a flat JSON object containing `api_name`, `skill_version: "1.0.3"`, and endpoint parameters. Wrapper methods map book info, highlights, progress, chapters, personal reviews, popular highlights, public reviews, reading stats, and paginated notebooks onto that primitive. `getChapters()` adapts V2's `{chapters}` response to the V1 shape expected by parsers. Sources: [`src/api-v2.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api-v2.ts), [`docs/weread-agent-api.md`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/docs/weread-agent-api.md).

- **V2/V1 routing.** `ApiRouter.useV2()` selects V2 whenever a key is non-empty. Common endpoints try V2 and then use V1 if V2 throws **or returns no result**. Public reviews and popular highlights are V2-only and return `undefined` on failure; article/公众号 highlights, reviews, and chapters are forced to V1. `getBookReadInfo()` and Cookie/key lifecycle operations are explicitly V1-only. Source: [`src/api-router.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api-router.ts).

- **Failure semantics and retries.** `ApiV2Manager.callAgent()` catches transport errors and converts non-zero `errcode` responses to `undefined`; it has no timeout, status classification, `Retry-After`, backoff, jitter, or 429/5xx retry policy. Upstream's only automatic retry is `ApiManager.getNotebooksWithRetry()`, which immediately repeats one V1 notebook request. Chapter popular-highlight requests run five at a time with `Promise.allSettled`, isolating per-chapter failures but not rate-limiting them; the detail view exposes a manual retry button. Sources: [`src/api-v2.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api-v2.ts), [`src/api.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api.ts), [`src/api-router.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api-router.ts), [`src/components/wereadBookDetailView.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/components/wereadBookDetailView.ts).

- **Bookshelf and notebook inventory.** Although the guide advertises `/shelf/sync`, the implemented bookshelf service calls `getNotebooksWithRetry()`, backed by V2 `/user/notebooks`, and merges that inventory with local files. It separately loads reading progress in chunks of four and caches progress in memory. `ApiV2Manager.getNotebooks()` follows `lastSort` with pages of 300, but has no repeated-cursor guard. Sources: [`docs/weread-v2-guide.md`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/docs/weread-v2-guide.md), [`src/bookshelf.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/bookshelf.ts), [`src/api-v2.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api-v2.ts).

- **Highlights, notes, and reviews.** `SyncNotebooks.convertToNotebook()` fetches detail, progress, personal highlights, personal reviews, and chapters, then normalizes them through `parseResponse.ts`. Highlights are joined to personal thoughts by `range`, grouped and sorted by chapter/range, while reviews are split into chapter notes and whole-book reviews by `type`. The detail view additionally fetches V2 popular highlights and public reviews concurrently with the core data. Sources: [`src/syncNotebooks.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/syncNotebooks.ts), [`src/parser/parseResponse.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/parser/parseResponse.ts), [`src/components/wereadBookDetailView.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/components/wereadBookDetailView.ts).

- **Popular-highlight cache and merge.** `PopularHighlightsCacheManager` implements per-book JSON read-through caching under `.weread-cache/`, with a configurable seven-day default TTL and expired-entry cleanup. On a miss, `SyncNotebooks.getPopularHighlights()` fetches chapters in batches of five, caches normalized results, and merges matches into personal highlights by exact `range`; unmatched popular highlights are inserted and all entries are range-sorted. Cache writes are overwrite-in-place rather than atomic, and stale data is not used after refresh failure. Sources: [`src/popularHighlightsCache.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/popularHighlightsCache.ts), [`src/syncNotebooks.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/syncNotebooks.ts).

- **Incremental synchronization.** The sync is selective full replacement, not endpoint-level delta application: `getLocalNotebookFile()` skips a book only when local `noteCount` and `reviewCount` equal remote values, unless force sync is requested. Changed text with unchanged counts, reading-only changes, and compensating add/delete operations can therefore be missed. `synckey` is documented by the API, but the source starts personal reviews at zero and does not persist per-book cursors. Sources: [`src/syncNotebooks.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/syncNotebooks.ts), [`src/api-v2.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api-v2.ts), [`docs/weread-agent-api.md`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/docs/weread-agent-api.md).

## Applicability to `weread2notion-pro`

The Python project has the stronger low-level gateway foundation: `WeReadGateway.request()` uses Bearer auth, a flat payload, explicit exceptions, four attempts, `Retry-After`, backoff, 429/499/5xx handling, and upgrade/error validation. `WeReadApi` normalizes those responses for the existing sync code, guards repeated notebook/review cursors, and paginates `/review/list/mine`, all improvements over upstream. The upstream snapshot reports Skill `1.0.3`; this project follows the installed official Skill at `1.0.4`. See `weread2notionpro/weread_gateway.py` and `weread2notionpro/weread_api.py`.

The Python bookshelf path already uses `/shelf/sync` and compares `readUpdateTime`, finish status, archive, cover, and rating state before updating Notion; note synchronization separately skips on the notebook `sort` value. This is broader than upstream's count-only check, while `select_sync_batch()` adds a rotating request-budget cap absent upstream. See `weread2notionpro/book.py`, `weread2notionpro/weread.py`, and `weread2notionpro/sync_batch.py`.

## Prioritized port list

1. **Port a capability-aware router, not upstream's error swallowing.** Add an interface/facade around the Python client only if Cookie V1 compatibility is still required; preserve typed Python exceptions and fall back only for explicitly recoverable/unsupported cases. Port the endpoint policy from `ApiRouter.useV2()`, `getNotebookHighlights()`, `getNotebookReviews()`, `getChapters()`, and V2-only methods. Source: [`src/api-router.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api-router.ts).

2. **Port persistent per-book sync state.** Extend Python's current `Sort` check with remote `noteCount`, `reviewCount`, `bookmarkCount`, and persisted `synckey`/last successful timestamp; advance state only after the Notion write succeeds. Use upstream `SyncNotebooks.getLocalNotebookFile()` and `filterNoteMetas()` as the starting concept, but avoid its count-only blind spots. Source: [`src/syncNotebooks.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/syncNotebooks.ts).

3. **Port popular-highlight caching and merge.** Implement an atomic per-book cache with configurable TTL, stale-if-error behavior, schema/version metadata, and exact-range merge into personal highlights. Upstream functions: `PopularHighlightsCacheManager.get/set/clearExpired()`, `SyncNotebooks.getPopularHighlights()`, `groupPopularByChapter()`, and `ApiRouter.getBestBookmarksBatch()`. Sources: [`src/popularHighlightsCache.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/popularHighlightsCache.ts), [`src/syncNotebooks.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/syncNotebooks.ts), [`src/api-router.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api-router.ts).

4. **Port the normalized note/review model.** Reuse `parseHighlights()`, `parseReviews()`, `parseChapterHighlightReview()`, and `parseChapterReviews()` concepts to produce one deterministic intermediate model before Notion mutation. Preserve `type=1/4/6`, HTML-to-Markdown conversion where needed, normalized IDs, chapter/range ordering, and highlight-to-thought association. Source: [`src/parser/parseResponse.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/parser/parseResponse.ts).

5. **Port bounded concurrency, retaining Python's stronger rate-limit control.** Add a configurable worker pool for independent per-book or per-chapter reads, use per-item failure isolation, and stop scheduling new work on `WeReadApiRateLimitError`. The upstream pattern is `ApiRouter.getBestBookmarksBatch()`; do not port its fixed concurrency of five without adaptive backpressure. Source: [`src/api-router.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api-router.ts).

6. **Optionally port credential validation/acquisition UX.** For an interactive Python setup command, validate with `/_list`, support manual `wrk-…` input, and optionally retrieve a key through Cookie-authenticated `/api/skills/apikeyGet`; avoid storing it in plaintext project files. Upstream functions: `ApiV2Manager.validateApiKey()`, `ApiManager.fetchAndSaveApiKey()`, and `WereadSettingsTab.handleScanApiKey()`. Sources: [`src/api-v2.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api-v2.ts), [`src/api.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/api.ts), [`src/settingTab.ts`](https://github.com/zhaohongxuan/obsidian-weread-plugin/blob/5d3b4214fb1430bd23125d69d1a5f42eca23dd9b/src/settingTab.ts).
